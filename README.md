# Autonomous Code Review Study

Reproducibility package for a retrospective benchmark of autonomous cross-provider code review.

## Contents

The complete release tree, including sanitized workflow and accounting tables, task provenance, the deterministic analysis script, protocol, and manuscript source/PDF, is available in [`autonomous-code-review-study.zip`](autonomous-code-review-study.zip). Verify the included SHA-256 values using `RELEASE_MANIFEST.json` after extracting the archive.

The numerical analysis can be reproduced offline with Python 3.12 and the command documented in the archive README.
